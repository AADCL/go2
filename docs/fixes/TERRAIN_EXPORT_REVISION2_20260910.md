## 根因及正式修复

1. 旧绝对 Z 投影会将抬升坡面写成黑色障碍。现在旧投影只提供地图尺寸和原点；PGM 障碍按连续地面的相对高度重新计算。
2. 仅沿稀疏相邻格增长会在扫描条纹处中断。现在使用 PMF 分布式候选、鲁棒平面连接和有限空隙重建；坡度建模上限仍为 35°。
3. 大支撑范围不能准确表示坡顶、坡脚。现在在拟合不一致时缩小支撑范围，保留连续折面，不放宽原误差门限。
4. 墙边缺失同格地面时，原分类会跳过真实墙点。现在仅对具有连续竖直点云证据的柱建立邻域地面参考；这个参考只用于保留实测障碍，不生成地面、自由区或坡度代价。
5. 大块悬空屋面不能仅凭分布式 PMF 种子成为地面。输出地面必须沿高度连续的表面连接到测得的起点地面。
6. 规则台阶不能因平面拟合而被抹成坡面。新增邻接实测高度跳变检查，保留至少 0.05 m 的连续台阶边缘。

缺少可靠参考的竖直结构保持未知。障碍证据总是覆盖地面和已行走自由证据。天花板的孤立高点不能充当连续墙体证据。

## 日常使用

```bash
run_go2 mapping 新地图名
# 遥控完成建图后，在另一个终端保存：
run_go2 save-map
# 建图终端 Ctrl+C，待进程退出。
run_go2 export-map 新地图名
```

命令、地图目录和文件命名保持一致，不再需要运行 V1/V2 临时脚本或逐张指定补墙参数。已有无地形资料的旧地图继续使用原兼容流程；已有 revision 1 地形地图继续按原版本契约校验。发布时验证 `lab_202609091725` 通过；更早的 `lab_202609091010`、`lab_202609091450`、`lab_202609091625` 仍带旧 0.10 门限，当前契约要求 0.08，须重新导出再使用，不能手改元数据绕过。

新导出完成后：

```bash
cat ~/go2_nav_ws/maps/新地图名/terrain_quality.yaml
rosrun go2_terrain validate_terrain_map.py \
  --map-dir ~/go2_nav_ws/maps/新地图名
```

校验输出中应出现 `revision=2`。所有 PGM 和六层文件同时生成；请勿把单张新 PGM 与旧的六层地形文件混用。

经人工检查新 PGM 后，导航仍使用原命令：

```bash
RVIZ=true run_go2 navigation 新地图名 --real
# 现场确认定位和环境后才由人员执行：
run_go2 enable
```

本次部署及验证没有运行上述导航或 Enable 命令，也没有发送运动目标。

## 输出和质量检查

新增 `terrain_quality.yaml`，记录实际地面覆盖、自由轨迹比例、从起点连通的轨迹比例、补回墙体格数、无参考竖直格数和台阶边缘格数。该文件与 PGM、六层、源 PCD 快照一起参与 SHA256 校验。

默认最低要求：地面格数 100；轨迹样本的地面覆盖 80%；实际 PGM 自由比例 95%；从起点自由连通比例 95%。这里不再把“黑色障碍也是已知格”误算成成功。连通检查不是机器人 footprint 可通行验证，狭窄通道仍需检查实际净宽和规划器结果。

全局坡度代价保持：≤8° 不增加；8–30° 软代价 15–80；连续至少四格 >30° 致命，横向扩展 0.20 m。局部仍无坡度层。0.03 m 地图膨胀在 0.05 m 栅格上按原规则取整为一格，因此实际沿四邻域扩展 0.05 m。

默认参数统一位于 `src/go2_terrain/config/terrain_export.yaml`。有效表面参数会写入 `terrain_2p5d.yaml`。不建议靠降低质量门限强行导出；输入缺地面、轨迹异常、墙体与行走记录矛盾、快照不一致时应查看具体错误并补扫。

## 备份、失败处理和回滚

部署备份目录：`~/go2_nav_ws/backups/codex_20260910_terrain_revision2`。保留修改前源码、配置、入口脚本、核心库、导出可执行文件、构建/测试日志和部署 SHA256。

单次导出先在临时目录生成和校验全部资产，再备份旧文件、依次替换，最后安装元数据。普通文件写入/替换错误会回滚旧资产。它不是文件系统级多文件事务；断电或强制结束恰好发生在替换期间时可能留下 `.go2_terrain_recovery_*`，校验器会拒绝混合版本。此时先用该目录恢复旧资产，校验通过后再导航，不要直接删除恢复目录。

需要退回旧程序时，先停止建图/导航，按备份 `files/` 的相对路径恢复文件，恢复 `run_go2_installed` 到 `~/.local/bin/run_go2`，然后重新编译 `go2_terrain`。新增文件列表与部署清单保存在实验目录。回滚程序不会自动回滚已经导出的新地图；地图回滚须恢复成套 PGM/YAML/六层及校验文件。

此版本消除了已确认的通用缺陷，但不能保证任何缺失、错位或严重遮挡的 PCD 都能生成正确导航地图。遇到证据不足时明确失败，是避免错误导航图进入真机的必要行为。

参考代码的版本与许可证说明见 `src/go2_terrain/THIRD_PARTY.md`。
