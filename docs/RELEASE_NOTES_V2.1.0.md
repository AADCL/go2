# GO2 V2.1.0 发布说明

发布日期：2026-09-10。基线为机器狗 1 `/home/nvidia/go2_nav_ws` 的实际源码和地图状态，在 `v2.0.1` 提交历史上继续发布。

本版修复室外上下坡被二维投影写成不可达区域，以及墙边缺少同格地面时墙体被漏掉的问题。修复进入正式 `go2_terrain` 库、默认配置、导出入口和校验器，对后续地图统一生效，没有按地图名称或红框坐标补图的分支。

## 算法与资产

- 使用分布式 PMF 候选、鲁棒局部平面和与起点地面连续的表面重建；坡顶/坡脚自适应缩小支撑范围。PGM 和六层地形资产使用同一地面模型，旧二维投影只提供地图几何信息。
- 障碍按局部地面相对高度提取。墙边缺地面时，根据可靠邻域地面和连续竖直点云证据保留实测墙体；该参考不新增地面、自由区或坡度代价。
- 排除断开的大块屋面和天花板，保留至少 0.05 m 的连续实测台阶边缘，支持无障碍场景的空障碍 PCD。
- 新增 `terrain_quality.yaml`，校验实际轨迹地面覆盖、PGM 自由比例及从起点连通比例；避免将黑色障碍的“已知”状态当作可通行。
- 所有资产在暂存目录生成和校验，再备份并替换旧资产，元数据最后提交；正常 I/O 失败回滚，异常中断保留恢复目录，由校验器拒绝混合版本。
- 文件格式仍为 version 1，表面重建标记为 `reconstruction_revision: 2`；满足现行资产契约的 revision 1 地图继续通过兼容校验。
- 同步 `validate_workspace.sh` 的 revision 2 默认参数检查及启动、导出和回滚文档。
- 纳入端侧实际使用的 Livox ROS1 `package.xml`（此前被上游忽略规则排除），使直接克隆后的 catkin 包发现完整；固定源码 LF 换行，并对地图文件禁用文本转换，保护资产 SHA256。

## 兼容与操作

命令保持不变：

```bash
run_go2 mapping 新地图名
run_go2 save-map
# 建图窗口 Ctrl+C，等待保存完成并退出。
run_go2 export-map 新地图名

RVIZ=true run_go2 navigation 新地图名 --real
# 现场确认定位、地图和环境安全后：
run_go2 enable
```

FAST-LIO、动态建图、NDT、TF、外参、实时局部地形处理、GlobalPlanner、TEB、底盘控制、Enable 逻辑和网络配置保持当前机器狗 1 状态。地图障碍膨胀参数为 0.03 m，全局/局部 costmap 膨胀为 0.10 m。全局坡度 ≤8° 无附加代价、8–30° 软代价、连续至少四格 >30° 致命；局部不加载坡度层。

机器狗 2/3 不随本次发布升级；其适配分支 `unitree-orin-nano` 保留。`v2.0.0`、`v2.0.1` 和所有已有提交保持不变。需要回滚时停止运行栈，在独立目录检出旧标签并重新编译，同时恢复与旧程序配套的完整地图资产；不要只替换单张 PGM。
