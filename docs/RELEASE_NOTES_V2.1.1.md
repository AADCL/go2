# GO2 V2.1.1 发布说明

发布日期：2026-09-12。在 `v2.1.0` 历史上追加发布，基线为机器狗 1 于 2026-09-11 已部署、编译和隔离回放验证的代码；发布前再次核对端侧源文件。

本版修复 Enable 未请求经典步态，以及坡道导航中正常的小幅高度波动导致地形保护取消目标的问题。`run_go2 navigation <map> --real`、`run_go2 enable` 和 RViz 发布目标的操作方式保持不变。

## 改动

- 默认底盘策略由 `direct_mcf` 改为 `classic_mcf`。每次 Enable 显式请求 `ClassicWalk(true)`（API 2049），失败保持 Disable 并报告 SDK 错误；不自动试用其他步态或重新选择控制器。
- 增加 DDS 遥测新鲜度检查、经典步态请求诊断及可见外部模式/姿态 API 接管检测。保持现有 Move 频率、速度整形和 no-step 监测，不周期性重发步态切换指令。
- 地形高度检查增加 2 cm 滞回：启动/恢复保持 0.43–0.59 m，已健康运行使用 0.41–0.61 m。超出范围后仍关闭许可，恢复仍需连续 5 帧通过原始范围。
- 地面连通、拟合 RMSE、点云超时与频率检查保持不变；新增诊断展示实际活动高度门限。
- 同步 README、启动手册、地形说明与端侧诊断/回滚文档。

## 验证

- 机器狗 1：`catkin_make --pkg go2_control go2_terrain -j2` 成功。
- 112 个测试用例通过：经典步态 5、地形模型 48、地形算法 31、离线地面/导出事务 12、Python 地图校验 16。
- 原工作空间 package、launch 和配置静态检查通过。
- 对 `2026-09-11-11-15-39.bag` 进行隔离回放：旧版复现约 58.8 秒和 66.8 秒开始的高度误停；启动稳定后统计中旧版有 22 条高度越界诊断，新版为 0。新版点云输入停止后仍正常关闭许可。
- 发布源码与端侧已验证代码一致；原启动脚本、外参和导航配置校验值不变。

回放只向独立 ROS master 发布两路地面分割点云，没有启动 SDK、导航或速度/目标发布器。**经典步态实际抬腿、持续保持及爬坡效果尚待现场验收**：本机 MCF 的 `mode/gait_type/foot_raise_height` 不能可靠确认步态，GetState 返回空内容。`classic_request_accepted=true` 仅表示接口回复成功，`classic_feedback_verified=false` 如实表示反馈限制。

## 兼容与历史

地图、建图及转换算法、FAST-LIO、NDT、TF、外参、GlobalPlanner、TEB、footprint、控制速度和网络配置保持 V2.1.0 及端侧既有状态。地图不重新生成，bag、构建产物和临时认证文件不纳入源码发布。

本次只更新 `main` 并创建 `v2.1.1`；保留 `v2.0.0`、`v2.0.1`、`v2.1.0`、机器狗 2/3 的 `unitree-orin-nano` 分支及其标签，不强推、不改写历史。

新固件未验证时不要把 MCF 或 API 成功返回当作实机步态保证。完整诊断、测试与本机备份回滚方法见 [经典步态与坡道误停修复](DEPLOYMENT_CLASSIC_GAIT_20260911.md)。旧版可在独立目录检出 `v2.1.0` 后重新编译。
